## 🚀 Sobre mí
Soy un **Arquitecto de Soluciones Móviles** con más de 9 años de trayectoria transformando ideas complejas en ecosistemas digitales escalables. Mi enfoque principal es el desarrollo nativo con **Android (Kotlin/Java)** y multiplataforma con **Flutter**, siempre bajo la premisa de que el código debe ser tan robusto como el negocio que representa.

Me apasiona el diseño de sistemas desacoplados, la optimización de rendimiento y la creación de arquitecturas que permitan a los equipos crecer sin fricciones.

## 🌟 Proyectos Destacados

### [🏗️ TypeScript Clean Architecture Blueprint](https://github.com/ja35obando/clean-architecture-ts)
Una implementación maestra de arquitectura por capas diseñada para Node.js y TypeScript. 
- **Lo que demuestra:** Dominio de inversión de dependencias, separación de lógica de negocio (Dominio) de detalles técnicos (Infraestructura) y testing profesional con Vitest.

- **Reto Técnico:** Sincronización de datos en tiempo real y entornos offline-first (Zero Configuration) para gimnasios sin conectividad.
- **Tech Stack:** Flutter, BLoC, Isar/Hive, WebSockets.
